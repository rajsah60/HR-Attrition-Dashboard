# HR-Attrition-Dashboard

# Objective:
Analyze employee attrition patterns and identify key workforce segments associated with employee turnover.

 📊 Dashboard KPIs

Some important numbers shown in the dashboard are:
-  Total Employees: 1470
-  Active Employees: 1233
-  Attrition Count: 237
-  Attrition Rate: 16.12%
-  Average Age: 37
-  Average Income: 6.5k


# Tools Used:
- Power BI
- DAX
- Power Query
- Data Cleaning & Transformation
- Data Visualization


📈 Dashboard Analysis

   The dashboard includes:
   - Attrition by Department
   - No. of Employees by Age Group
   - Job Satisfaction Rating
   - Attrition by Education Field
   - Attrition by Gender for different Age Groups
   - Education Filter


###  Business Recommendations 

- Investigate retention challenges within R&D and Sales.
- Develop targeted retention program for employees aged 25-34.
- Analyze career progression, compensation and workload for high-attrition employee segments.
- Conduct employee engagement/satisfaction surveys to understand the reasons behind turnover.
